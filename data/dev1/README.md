### `dev1/`
Contains all data relevant to dev1 dataset including annotated usages

````
📁 dev1/
├── 📁 annotations_Felix/
├── 📁 annotations_Johannes/
├── 📁 annotations_Nikolay/
├── 📁 dictionaries/
├── 📁 raw_usages/
````

* annotations_Felix, annotations_Johannes, annotations_Nikolay: Per annotator contains 108 annotated usages
* raw_usages: Raw usages which can be given as input to the pipeline to evaluate on the given annotations
* dictionaries: ODE and LEMUR dictionaries which can be given as input to the pipeline to evaluate on the given annotations
